# Changelog

## 0.1.0 · 2026-10-31

First public prototype.

- Single-page app: product setup, report import (Amazon search terms, Google Ads search terms, Business Report), weekly run and history.
- Rule book R1–R6 with per-product prices, brand protection and configurable blocked words; Python CLI with identical output.
- Statistics and ML: week-8 forecasts with 80% intervals, trend-controlled ad-spend effect test, silhouette-tuned k-means term groups, binomial slow-bleeder test, trend-residual alerts, cannibalisation check, overlap correction for 14-day reports.
- Decision engine: budget call and ranked priorities with ₹ impact; 8-week PASS / ITERATE / FAIL scorecard.
- Optional AI brief with Claude (bring your own key) or copy-prompt.
- Excel report: dashboard with KPI tiles, decision, priorities, charts and findings, plus six detail sheets.
- Tests (Python and Node) and GitHub Actions workflow.
